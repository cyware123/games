Enroque · Abre y juega

10.000 problemas reales, repertorio ECO y Stockfish. No necesitas Internet, instalar programas ni iniciar un servidor.

Opción 1: archivos separados

Conserva la carpeta completa y abre index.html con doble clic. HTML, CSS y JavaScript están separados para poder editarlos.

Opción 2: un solo archivo portátil

Abre enroque-portatil.html. Ese HTML incluye todo, incluso los problemas y Stockfish; puedes copiarlo solo a otra carpeta.

Usa Chrome, Edge o Firefox actualizado. En celular necesitas un navegador que ejecute JavaScript en archivos locales; un visor de documentos puede mostrar solo una vista previa.

Ayuda tras tres fallos

En cada movimiento, al tercer intento incorrecto se marcan origen y destino. Al acertar desaparecen. Si vuelves a necesitar ayuda, el contador vuelve a funcionar.

Audio

Selecciona español o inglés. Para escuchar sin Internet necesitas una voz local instalada; también puedes entrenar con texto.
